# 💗 For You — a mood-reactive love letter

A romantic, animated, one-page website that changes its whole tone with each
section (soft · tender · playful · spicy), floats hearts and petals, and has a
little cat companion that meows 🐱. Built to be **foolproof**: you only ever
change words in one file and drop photos in one folder.

No installs, no build step, no internet needed to run.

---

## ✨ How to see it right now
Just **double-click `index.html`** — it opens in your browser. Done.

## 🖼️ How to add your photos (the only real step)
1. Open the **`photos`** folder.
2. Save your pictures there using the names listed in
   `photos/PUT-YOUR-PHOTOS-HERE.txt` (e.g. `us-1.jpg`, `gallery-1.jpg`).
3. Refresh the page. Your photos appear automatically. 💕

Until a photo is added, its spot shows a pretty animated placeholder — so it
never looks broken while you fill them in.

## ✍️ How to change the words (optional)
Open **`config.js`** and edit the text between the quotes — her name, the love
notes, the letter, everything. You cannot break the design by editing text.

---

## 🌈 What makes it special
- **Mood engine** — the palette, glow, and particles re-tint as she scrolls:
  loving → *soft rose*, emotional → *tender lavender*, fun → *playful peach*,
  intimate → *spicy crimson*.
- **Always alive** — drifting glows, floating hearts/petals, breathing text,
  a swishing-tail cat that blinks and meows.
- **Cats 🐱** — tap the cat for a meow + heart burst; it also chirps on its own.
- **Tap anywhere** for a burst of little hearts.
- **The finale** — the "I love you" button sets off a shower of hearts + meows.
- **Music** — tap 🎵 for a soft ambient chord (synthesized, optional).
- Works on phone and laptop, and respects "reduce motion" accessibility.

> Everything (meows, music, hearts) is generated in the browser — there are no
> sound files to manage, so nothing can go missing.

## 🚀 Put it on GitHub (so you can open it on your own laptop)
This is a plain static site, perfect for **GitHub Pages** (free).

1. Create a new repository on GitHub, e.g. `for-her`.
2. Upload **all** the files in this folder (keep the `photos` folder inside).
3. In the repo: **Settings → Pages → Build and deployment → Source: Deploy
   from a branch → Branch: `main` / root → Save.**
4. Wait ~1 minute. Your private link appears at the top of the Pages settings,
   like `https://your-username.github.io/for-her/`.
5. Open that link on any device. 💗

> Prefer to keep it just between you two? You don't even need GitHub Pages —
> download the repo as a ZIP on your personal laptop and double-click
> `index.html`. It works fully offline.
